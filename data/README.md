# Датасет оттока клиентов

**Источник:** генератор `src/data/generate.py` (`make data`), сид и размер из `params.yaml` (`seed: 42`, `n_samples: 20000`).

**Обновление:** датасет статичный, пересоздаётся `make data`. Версии хранятся в DVC (remote `minio`).
Флаг `--drift` генерирует данные «следующего квартала» для мониторинга дрейфа (занятие 15).

**Объём:** 20000 строк, 12 колонок, доля оттока 20.6 %.

## Поля

| Поле | Тип | Единица | Диапазон | Комментарий |
|---|---|---|---|---|
| customer_id | str | — | `C0000000`–`C0019999` | идентификатор клиента, в модель не идёт |
| tenure_months | int | месяцы | 1–72 | стаж клиента |
| monthly_charges | float | руб./мес | 15–113 | текущий тариф, генератор ограничивает 15–180 |
| total_charges | float | руб. | 13.89–7462.29 | сумма списаний за всё время, около 1 % пропусков |
| contract_type | str | — | `month-to-month`, `one_year`, `two_year` | тип контракта |
| internet_service | str | — | `fiber`, `dsl`, `none` | тип подключения |
| payment_method | str | — | `electronic_check`, `mailed_check`, `bank_transfer`, `credit_card` | способ оплаты |
| num_support_calls | int | звонки | 0–7 | обращения в поддержку |
| has_tech_support | int | — | 0/1 | подключена техподдержка |
| avg_monthly_gb | float | ГБ/мес | 0.5–186.9 | средний трафик в месяц |
| is_senior | int | — | 0/1 | клиент пенсионного возраста |
| churn | int | — | 0/1 | **целевая переменная**: клиент ушёл |

## Известные дефекты

- `total_charges` пустой у 200 строк (1 %). Пропуски случайные, стаж у таких клиентов от 1 до 72 месяцев,
  поэтому «новый клиент без списаний» их не объясняет. `src/data/prepare.py` заполняет их как
  `monthly_charges × tenure_months`.
- `total_charges` не равен точно `monthly_charges × tenure_months`: отношение от 0.92 до 1.05
  (в генераторе заложен случайный множитель).
- Классы несбалансированы: отток 20.6 %. Порог 0.5 для F1 занижает полноту (см. `reports/EXPERIMENTS.md`).
